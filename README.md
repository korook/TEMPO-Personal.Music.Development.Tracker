# Tempo

A personal guitar practice website: measured practice sessions, a chord library generated from theory,
and eight ear-training games.

**Live site:** https://korook.github.io/TEMPO-Personal.Music.Development.Tracker/

- `npm run dev`: run it locally
- `npm test`: run the tests
- `npm run preview:file`: build single-file previews in `preview/` that open straight from the Finder

The plan is in [TEMPO_PLAN.md](TEMPO_PLAN.md). Every push to `main` republishes the live site.
